# HAVEN – Hotel Booking Website

HAVEN is a fullstack hotel booking application built as a school project. Users can explore rooms and make reservations, while administrators can manage bookings through a separate admin dashboard.

**Live Demo:** https://haven-five-dusky.vercel.app/
(The live version is a frontend demo. Booking and admin functionality require the backend to run locally.)

## Features
- Responsive hotel website with room details
- Room booking system
- Admin login and dashboard
- Create, view, edit and delete bookings

## Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express
- **Database:** SQLite
- **Authentication:** Express Session, bcrypt

## Getting Started

Install dependencies in both the root directory and `client`:

```bash
npm install
```

Start the backend from the root directory:

```bash
node server.js
```

Start the frontend from `client`:

```bash
npm run dev
```
